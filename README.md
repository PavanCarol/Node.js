# Node.js
Formação de Node.js na plataforma Rocketseat.

#RF (requisitos funcionais)

- [] O usuario deve porder criar uma nova transação;
- [] O usuario deve poder obter um resuo da sua conta;
- [] O usuario deve poder listar todas trasações que já ocorrera.
- [] O usuario deve poder visualizar uma transação única

#RN (regra de negocio)

- [] A transação pode ser do tipo: 
    - Crédito que somará ao valor total
    - Debito subtraira 
- [] Deve ser possivel identificarmos o usuario entre as requisições
- [] O usuario só pode visualizar transações o qual ele criou
